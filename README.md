# JDBC Project Collection

This repository contains a collection of JDBC mini-projects developed as part of hands-on practice sessions, lab exercises, and class assignments. Each folder represents a separate project based on different JDBC concepts such as CRUD operations, PreparedStatement, CallableStatement, Transactions, Metadata handling, and more.

## 📁 Project List

Here are the topic-wise folders included in this repository:

- 🔹 **Dec09_Lab_JDBC_App_1stDay** – Introduction to JDBC and basic database connection
- 🔹 **Dec10_class_JDBC_Assmt_01** – Simple CRUD operations using Statement
- 🔹 **Dec11_Lab_JDBC_App_2st** – Using PreparedStatement for secure input
- 🔹 **Dec12_Lab_JDBC_App_Employee** – Inserting and retrieving employee data
- 🔹 **Dec13_Lab_JDBC_App_EmpTable** – Working with Employee table using JDBC
- 🔹 **Dec13_class_DBC_App_Assn** – Class assignment on JDBC concepts
- 🔹 **Dec16_Lab_JDBC_App_Resume** – Storing and retrieving resumes (BLOB handling)
- 🔹 **Dec18_class_DBC_App_CVCexel** – Read/Write data from database to Excel
- 🔹 **Dec18_class_DBC_App_prepareCall** – Calling stored procedures using CallableStatement
- 🔹 **Dec19_Lab_JDBC_StoreDate_Image** – Storing date and image (BLOB & DATE data types)
- 🔹 **Dec20_Lab_JDBC_DataDBTo_List_To_File** – Fetching data and writing to file
- 🔹 **Dec21_class_DBC_App_OUT_Procedure** – Handling OUT parameters in stored procedures
- 🔹 **Dec23_class_DBC_TransactionAppBank** – JDBC transaction management in a banking scenario
- 🔹 **Dec26_class_FUNCTION_TO_GET_Name** – Using functions in database to retrieve values
- 🔹 **Dec27_class_MetaData** – Exploring database metadata with JDBC
- 🔹 **Dec30_Lab_JDBC_ResultsetTOListOfEmpList** – Converting ResultSet to List of Employee objects

## 🛠️ Technologies Used

- Java (JDK 17 or above)
- JDBC API
- Oracle Database
- IDE: Eclipse
- File handling, BLOB/CLOB operations
- Stored procedures and functions

## 🚀 How to Run

1. Clone the repository:
https://github.com/vimlGit/JDBC-Project-Collection

2. Open the desired project in your preferred IDE.
3. Configure your database connection (DB URL(jdbc:oracle:thin:@localhost:1521:xe), username, password).
4. Run the `main()` method to execute the application.

✅ Ensure your Oracle database service is running and schema is set up before execution.
